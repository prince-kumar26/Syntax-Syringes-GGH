# BloodLink AI

Gemini-assisted emergency blood request and donor coordination prototype.

## Problem
Families and hospitals may struggle to coordinate blood requests
and discover potential donors quickly.

## Solution
BloodLink AI structures requests and demonstrates rule-based
filtering of fictional donor records.

## Technology Stack
- React
- Node.js
- Express
- Google Gemini API (when configured)
- MongoDB (planned; not yet integrated in this starter)

## Current Prototype
- Request form and basic parsing
- Fictional sample donor matching
- Simulated notification workflow
